# Be careful!
## by Artyom Abramov and Pavel Zhivushko
Игра - аналог раннее популярного проекта Dumb Ways To Die.  
В сути это сборник динамичных мини игр на 10-20 секунд каждая. Игра распределена по уровням: максимум 60 секунд на уровень. Фишка игры - иммерсивность (использование акселерометра телефона, микрофона, кнопок громкости).  
Предполагаются разные тематические сценарии уровней.  
Игра должна обладать линейной сложностью, то есть чем старше уровень - тем сложнее. Усложнение будет происходить за счёт уменьшения временного лимита, уменьшения кол-ва жизней на уровень, снижения чувствительности управления.
## Технологический стек
### 🖥Разработка: Godot + gdscript
### 🖼Графика и анимация: Figma + Krita + DragonBones
### 🎧Музыка: FL studio
Применение скелетной анимации из программы DragonBones осуществлятся с помощью аддона [Godot-DragonBones Plugin](https://github.com/Daylily-Zeleen/Godot-DragonBones.git)
## Актуальное состояние разработки
### ✅Реализованные мини-игры
1. Игра-тапалка (нажимайте быстро по экрану, чтобы ускориться и убежать от врага, продержитесь 5 секунд)

### ✏Мини-игры в процессе разработки
1. PullGame (качайте насос с помощью слайда по экрану, достигните нужного уровня давления, но не перекачайте)

### 📋Планиуруемые мини-игры
1. Задуй огонь (дуйте в микрофон, чтобы предмет не успел сгореть)
2. Держи равновесие (в горизонтальном положении экрана персонажа наклоняет в сторону, наклолните в другую сторону телефон, чтобы выровнять)
3. Ударь бобра (реализация популярной игры, где нужно максимально быстро отреагировать на событие и нажать в нужное место)
