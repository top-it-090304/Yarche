# Be careful!
## by Artyom Abramov and Pavel Zhivushko
Игра - аналог раннее популярного проекта Dumb Ways To Die.  
В сути это сборник динамичных мини игр на 10-20 секунд каждая. Игра распределена по уровням: максимум 60 секунд на уровень. Фишка игры - иммерсивность (использование акселерометра телефона, микрофона, кнопок громкости).  
Предполагаются разные сценарии с разными мини-играми.  
Предполагается линейная сложность - то есть чем старше уровень - тем сложнее. Усложнение будет происходить за счёт уменьшения временного лимита, уменьшения кол-ва жизней на уровень, снижения чувствительности управления.
